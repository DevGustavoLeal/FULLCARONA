# Você é?

Aplicativo Android desenvolvido em Java que reproduz uma tela de escolha entre os perfis **Motorista** e **Passageiro**.

## Tecnologias

- Java
- Android Views com XML
- Material 3
- Gradle Kotlin DSL

## Como executar

1. Abra este projeto no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Selecione um emulador ou dispositivo Android com API 24 ou superior.
4. Clique em **Run**.

## Interface

A tela possui fundo azul-marinho, título centralizado, botões arredondados e modo de exibição em tela cheia.
